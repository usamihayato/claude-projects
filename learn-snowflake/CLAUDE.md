# CLAUDE.md

## 役割

Snowflakeの学習者として、SnowPro Core認定資格の取得を目指している。

## 目標

SnowPro Core認定資格（COF-C03）の取得。まずは基礎固めとして、公式ドキュメント（docs.snowflake.com/ja）を出題分野ごとに読み込む。並行してUdemyの模擬試験で間違えた問題を整理し、弱点分野を把握する。

### 試験概要

- 試験コード: COF-C03（2026年2月版が最新）
- 受験対象: Snowflakeでの6か月以上の実務経験

### 出題分野と配点

| 分野 | 配点 |
|---|---|
| 1.0 Snowflake AIデータクラウドの機能とアーキテクチャ | 31% |
| 2.0 アカウント管理およびデータガバナンス | 20% |
| 3.0 データのロード、アンロード、および接続 | 18% |
| 4.0 パフォーマンス最適化、クエリ、および変換 | 21% |
| 5.0 データコラボレーション | 10% |

各分野の詳細サブトピック（1.1〜5.3）は公式試験学習ガイド `snowflake-docs/SnowProCoreStudyGuideC03_JPN.pdf` を参照。

## 演習ツール

`quiz/index.html` に、分野別出題・誤答のみの再出題ができる演習ツール（過去問道場スタイル）を用意している。
ブラウザで開くだけで動作し、解答履歴は localStorage に保存される。
問題データの追加方法とスキーマは `quiz/README.md` を参照。

## 制約

- 公式ドキュメント（docs.snowflake.com/ja）をベースに情報をまとめること
- 演習ツールに登録する問題は、市販教材やUdemy等の問題文を転記せず、公式ドキュメントをもとにしたオリジナルとすること（誤答した「論点」をメモし、自分の言葉で類題を作る運用とする）
- `snowflake-docs/` 配下の公式PDFは内部使用限定のため、内容を転記・複製せず、あくまで参考資料として扱うこと（要約作成時も出典は必ずdocs.snowflake.comの公式ページとする）
- 公式ドキュメント読み込みリストは `docs/reading-list.md` の1ファイルに集約し、ファイル内を分野別（0〜5）の見出しで整理する（分野ごとにファイルを分割しない）
- 学習内容のまとめ（`notes.md`）やUdemy誤答整理（`udemy/`）は、読み込みリスト整備が完了してから着手する
