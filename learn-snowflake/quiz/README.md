# SnowPro Core 演習ツール

SnowPro Core（COF-C03）の学習用に、IPA「過去問道場」スタイルの演習ツールです。
分野別に出題し、**間違えた問題だけを再出題**できます。

- 外部ライブラリ・ビルド不要。`index.html` をブラウザで開くだけで動作します
- 解答履歴はブラウザの localStorage に自動保存されます
- オフラインで動作します（スマホに `index.html` を1ファイル送るだけでも使えます）

---

## 使い方

`index.html` をブラウザで開きます。

```
# ローカルでファイルを直接開く
open learn-snowflake/quiz/index.html          # macOS
xdg-open learn-snowflake/quiz/index.html      # Linux
```

### 画面構成

| 画面 | できること |
|---|---|
| 出題設定 | 分野・セット・出題モード・出題数・出題順を選んで演習を開始する |
| 出題 | 解答すると即時採点され、解説と出典リンクが表示される |
| 演習結果 | 正答率と分野別内訳を確認し、**間違えた問題だけ再挑戦**できる |
| 履歴・データ | 問題ごとの成績確認、JSONのエクスポート／インポート、履歴の削除 |

### 出題モード

| モード | 内容 |
|---|---|
| 通常 | 選択した分野の全問から出題 |
| 誤答のみ | 過去に1回でも誤答した問題のみ出題（復習用） |
| 未回答のみ | まだ一度も解答していない問題のみ出題 |

出題モードは、セットを選んでいる場合は**そのセットの中だけ**に適用されます。
たとえば「セット2 + 誤答のみ」なら、q101〜q200 のうち誤答した問題だけが出題されます。

### セット

100問ごとのまとまりを「セット」として選べます。プルダウンは登録済みの問題から自動生成され、
各セットの ID 範囲と問題数が表示されます。

| 判定方法 | 内容 |
|---|---|
| `set` フィールド | 問題データに `"set": 2` のように指定があればそれを優先 |
| ID の末尾数字 | 指定が無ければ ID 末尾の数字を100問ごとに区切る（`q001`〜`q100` → セット1、`q101`〜`q200` → セット2） |

ID の末尾に数字が無く `set` の指定も無い問題は、どのセットにも属さず「すべてのセット」でのみ出題されます。

### キーボードショートカット

| キー | 動作 |
|---|---|
| `1` 〜 `9` | 選択肢の選択／解除 |
| `Enter` | 解答する／次の問題へ |

## 問題の追加方法

問題データの追加には2つの方法があります。用途に応じて使い分けてください。

### 方法A: `index.html` を直接編集する（推奨）

`index.html` の末尾付近にある以下のブロックを編集します。

```html
<script type="application/json" id="question-bank">
[
  { ... 問題 ... },
  { ... 問題 ... }
]
</script>
```

この方法で追加した問題は git 管理下に入り、端末を変えてもそのまま使えます。
問題の管理はこちらを正とすることをおすすめします。

> **注意**: JSON内に `</script>` という文字列を含めないでください。HTMLのパースが壊れます。

### 方法B: UIからJSONをインポートする

「履歴・データ」画面の **JSONをインポート** から、問題を書いた JSON ファイルを読み込みます。
インポートした問題は localStorage に保存され、同梱の問題とマージされます。

`questions.sample.json` がテンプレート兼サンプルです。これをコピーして編集してください。

同じ `id` の問題をインポートすると内容が上書きされます（同梱バンクの問題も上書きできます）。

## 問題データのスキーマ

```json
{
  "id": "q001",
  "domain": 1,
  "subtopic": "1.5",
  "type": "single",
  "question": "問題文をここに書く",
  "choices": ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
  "answer": [0],
  "explanation": "解説をここに書く",
  "source": "https://docs.snowflake.com/ja/user-guide/...",
  "tags": ["Time Travel"]
}
```

| フィールド | 必須 | 内容 |
|---|:---:|---|
| `id` | ✓ | 問題の一意なID（文字列）。履歴はこのIDで紐づくため、後から変更しないこと |
| `domain` | ✓ | 出題分野。`1`〜`5` の数値 |
| `type` | ✓ | `"single"`（単一選択）または `"multiple"`（複数選択） |
| `question` | ✓ | 問題文。改行はそのまま表示される |
| `choices` | ✓ | 選択肢の配列（2件以上） |
| `answer` | ✓ | 正解の選択肢インデックス配列（**0始まり**）。`single` の場合は必ず1件 |
| `explanation` | | 解説文 |
| `source` | | 出典URL。解説の下にリンクとして表示される |
| `subtopic` | | サブトピック番号（例: `"1.5"`）。出題画面のバッジに表示される |
| `tags` | | タグの配列。解説欄に表示される |
| `set` | | セット番号（1以上の数値）。省略時は `id` 末尾の数字から100問単位で自動判定される |

### 出題分野の対応表

| domain | 分野 | 配点 |
|:---:|---|---:|
| 1 | Snowflake AIデータクラウドの機能とアーキテクチャ | 31% |
| 2 | アカウント管理およびデータガバナンス | 20% |
| 3 | データのロード、アンロード、および接続 | 18% |
| 4 | パフォーマンス最適化、クエリ、および変換 | 21% |
| 5 | データコラボレーション | 10% |

### 検証について

不正な問題データは読み込み時に検出され、画面上部に警告が出たうえで読み飛ばされます。
`answer` のインデックス範囲、`type` と `answer` 件数の整合性などが確認されます。

## データの持ち運び・バックアップ

解答履歴とインポートした問題はブラウザの localStorage に保存されるため、
**ブラウザのデータを消すと失われます**。また端末やブラウザをまたいで共有されません。

「履歴・データ」画面の **JSONをエクスポート** でバックアップを取得できます。
出力されたファイルをそのままインポートすれば、別の端末でも履歴を復元できます。

```json
{
  "version": 1,
  "history": { "q001": { "correct": 3, "wrong": 1, "lastAnsweredAt": "...", "lastResult": "correct" } },
  "sessions": [ { "startedAt": "...", "total": 10, "correct": 7 } ],
  "customQuestions": []
}
```

インポート時、この形式のファイルは**バックアップの復元**として扱われ、現在の履歴を置き換えます
（確認ダイアログが出ます）。問題だけを追加したい場合は、問題の配列だけの JSON を使ってください。

## 同梱の問題について

`index.html` の同梱バンクは空です。問題は上記の方法A（直接編集）か方法B（インポート）で追加してください。
`questions.sample.json` の `sample-1xx` は、**ツールの動作確認用に用意した自作のサンプル問題**です。

問題は公式ドキュメント（docs.snowflake.com/ja）の内容をもとに作成したオリジナルです。
市販教材や Udemy 等の模擬試験の問題文をそのまま転記することは、規約・著作権上避けてください。
誤答した問題は「論点」をメモして、自分の言葉でオリジナルの類題を作る運用を推奨します。
